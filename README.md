# Expense Tracker

A web-based Expense Tracker that helps users record, organize, and review their daily expenses through a simple and user-friendly interface.

## Features

* User registration and login
* Credential verification during login
* Add new expenses with:

  * Expense name
  * Amount
  * Category
  * Date
* View recorded expenses
* Delete expenses
* Filter expenses by category
* Calculate total expenses
* Dynamic pie chart for visualizing expenses by category
* Logout functionality

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Application Flow

```text
Register
   ↓
Login
   ↓
Home
   ↓
Add Expense / View Expenses
   ↓
Filter & Analyze Expenses
```

## How to Run

This project does not require Node.js, npm, or any additional server setup.

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Register an account and log in to access the Expense Tracker.

## Expense Analysis

The application provides a category-based view of recorded expenses. Users can filter expenses by category, while the total amount and pie chart update according to the displayed expense data.
